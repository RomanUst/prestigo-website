<interfaces>
EspoCRM 10.0.8 rules (RESEARCH Pattern 2, source-verified):
- createEntity: POST /EntityManager/action/createEntity {name:'Booking', type:'Base', labelSingular:'Booking', labelPlural:'Bookings', stream:false} -> {name:'CBooking'} (custom entities get a C prefix; a tab is added automatically)
- createLink: POST /EntityManager/action/createLink {linkType:'manyToOne', entity:'CBooking', link:'contact', entityForeign:'Contact', linkForeign:'bookings', label:'Contact', labelForeign:'Bookings'} -> Contact side link name `cBookings` (stock-scope side gets a c prefix). Same for account -> Account.
- fields: create POST /Admin/fieldManager/{scope} {name, type, ...params}; update PUT /Admin/fieldManager/{scope}/{finalName}. Final name: custom scope (CBooking, CPartnerRate) keeps the name; stock scope (Account, Contact, Opportunity) gets 'c' + Ucfirst(name). Only params permitted for the type persist (metadata `fields.{type}.params` plus `fields.{type}.fieldManagerAdditionalParamList`).
- existence/read: GET /Metadata/action/get?key=scopes.CBooking | entityDefs.CBooking.fields.{name} | entityDefs.CBooking.links.{link} (null when absent)
- layouts: GET/PUT /{scope}/layout/{name}
- every metadata write is sequential (the client already serializes) and rebuilds the cache itself

Config file shapes (later plans extend the same files):
- entities.json: `{ "entities": [ {name, type, labelSingular, labelPlural, stream} ], "links": [ {entity, link, linkType, entityForeign, linkForeign, label, labelForeign} ] }`
- fields.json: `{ "fields": { "CBooking": [ { "name": "...", "type": "...", ...params } ] } }`; local-only key `commercial` (plan 80-06) is never sent; create-only keys `label`, `translatedOptions`, `tooltipText` are sent on create but excluded from the diff (owner may relabel in the UI)
- layouts.json: `{ "layouts": [ { "scope", "name", "mode": "replace" | "append", "layout": [...] } ] }`; replace = ours (custom entities); append = stock scopes, add missing items/panels only, never remove or reorder

CBooking field contract: see plan 80-03 interfaces (identical names, types, options, maxLength). vehicleClass labels: business 'E-Class', first_class 'S-Class', business_van 'V-Class'; source labels: online 'Website', manual 'Admin-created', gnet 'GNet'; paymentMethod labels as values; status labels: Title Case of the value with '_' -> ' '.
