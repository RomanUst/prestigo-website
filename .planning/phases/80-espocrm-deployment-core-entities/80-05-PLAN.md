<interfaces>
mergeEnumOptions({ desired: [{value, label}], current: string[], currentLabels: {value: label}, retire: string[], inUse: Set }) -> { options, translatedOptions, removed: string[] }
- options = desired values (desired order) ++ current values that are neither desired nor (retired AND not in use), original order
- translatedOptions = currentLabels ∪ { desired label for a value whose current label is missing or equals the value itself (stock identity label) } — a label that differs from both the value and the desired label is an owner rename and is kept
- removed = retired values that were present and not in use

Stored values and labels (RESEARCH Pattern 3):

| field | value | label |
|---|---|---|
| Opportunity.stage | New | New |
| | First Contact | First contact |
| | Meeting | Meeting / call |
| | Rate Sent | Rate sent |
| | Trial Ride | Trial ride |
| | Closed Won | Partner (Won) |
| | Closed Lost | Lost |
| Account.type | Hotel | Hotel |
| | Agency | Travel agency / DMC |
| | Corporate | Corporate |
| | Embassy | Embassy / event agency |
| | Other | Other |

probabilityMap (stage, [ASSUMED] A1, owner may edit): New 10, First Contact 20, Meeting 40, Rate Sent 60, Trial Ride 80, Closed Won 100, Closed Lost 0. style: Trial Ride primary, Closed Won success, Closed Lost info. Opportunity stage default: New.
Retire lists (D-20): Opportunity.stage Prospecting, Qualification, Proposal, Negotiation; Account.type '', Customer, Investor, Partner, Reseller.
Read paths: GET /Metadata/action/get?key=entityDefs.{scope}.fields.{field} (options, default, probabilityMap, style); GET /I18n (labels at `{scope}.options.{field}`); in-use: GET /{scope}?select=id&maxSize=1&where[0][type]=equals&where[0][attribute]={field}&where[0][value]={v} (use type isEmpty for ''), total > 0 means in use.
Write: PUT /Admin/fieldManager/{scope}/{field} with { options, translatedOptions, default?, probabilityMap?, style? } — the PUT replaces the whole translatedOptions map, so always send the merged map.
enums.json shape: `{ "enums": [ { "scope", "field", "values": [{value,label}], "retire": [...], "default"?, "probabilityMap"?, "style"? } ] }`
</interfaces>
