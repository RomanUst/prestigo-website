- `merge {current} {overlay} --out {file}` prints `merge: added=...` or `merge: unchanged`

- `probe-unique` (admin API): creates CBooking { name: 'unique-probe', supabaseBookingId: 'unique-probe-{timestamp}-{random}' }, attempts the same again, deletes whatever was created; prints `unique=enforced` (exit 0) or `unique=absent` (exit 3)
