Build the durable outbox core and make all three site forms persist every submission into a new `inquiries` table, with the inquiry INSERT itself enqueuing a PII-free outbox row in the same transaction. The tracer proves the contact form path end to end (form route -> inquiries -> trigger -> outbox -> QStash publish scheduled after the response); the corporate and multi-day forms then join the same path; finally both migrations go live.

Purpose: LEAD-01/02/03 storage half and LEAD-05 (zero regression, D-18). Plans 81-07/09/10 deliver these outbox rows to EspoCRM; Phase 82 extends the same outbox.
Output: migrations 064/065 (applied live), lib/outbox.ts, lib/inquiries.ts, three updated form routes, tests.
</objective>

New contracts this plan creates (later plans import them verbatim):
- Table `public.integration_outbox`: id uuid pk default gen_random_uuid(); event_type text not null; aggregate_type text not null; aggregate_id uuid not null; idempotency_key text not null (CHECK char_length 1..120, UNIQUE index `integration_outbox_key_idx`); status text not null default 'pending' CHECK in (pending, processing, sent, skipped, failed); attempts int not null default 0; available_at timestamptz not null default now(); lease_until timestamptz; last_error text CHECK (last_error IS NULL OR last_error ~ '^[a-z0-9_]{1,40}$'); created_at, updated_at timestamptz not null default now(); sent_at timestamptz. Indexes: due index on (available_at) WHERE status IN ('pending','processing'); aggregate index on (aggregate_type, aggregate_id). BEFORE UPDATE trigger sets updated_at (migration 042/046 convention).
- Table `public.integration_config` (key text primary key, value text not null, updated_at timestamptz not null default now()). Seeds NOTHING — the `lead_capture_start` key is written at go-live (plan 81-11); its absence means booking capture is off (plans 81-09/10).
- `public.outbox_enqueue(p_event_type text, p_aggregate_type text, p_aggregate_id uuid, p_key text, p_available_at timestamptz DEFAULT now()) RETURNS boolean` — INSERT ... ON CONFLICT (idempotency_key) DO NOTHING; true when a row was inserted.
- `public.outbox_claim(p_key text, p_lease_seconds integer) RETURNS SETOF public.integration_outbox` — looks up the row's aggregate, takes `pg_advisory_xact_lock(hashtextextended(aggregate_type || ':' || aggregate_id::text, 0))`, then one UPDATE setting status 'processing', lease_until now()+lease, attempts attempts+1, updated_at now() WHERE idempotency_key = p_key AND available_at <= now() AND (status = 'pending' OR (status = 'processing' AND lease_until < now())) AND NOT EXISTS (another row of the same aggregate with status 'processing' AND lease_until > now()) RETURNING *.
- `public.outbox_complete(p_key text, p_status text, p_error_code text DEFAULT NULL) RETURNS boolean` — p_status must be sent|skipped|failed (else raise); UPDATE ... WHERE idempotency_key = p_key AND status = 'processing'; sets lease_until null, last_error p_error_code, sent_at now() when sent.
- `public.outbox_reschedule(p_key text, p_available_at timestamptz, p_error_code text) RETURNS boolean` — UPDATE status 'pending', available_at, lease_until null, last_error WHERE idempotency_key = p_key AND status = 'processing'.
- Every function: `LANGUAGE plpgsql` (or sql) `SECURITY DEFINER SET search_path = ''`, fully schema-qualified names, then `REVOKE EXECUTE ... FROM PUBLIC, anon, authenticated;` and `GRANT EXECUTE ... TO service_role;` (memory: DROP+CREATE re-grants PUBLIC; 063 pattern).
- Table `public.inquiries`: id uuid pk default gen_random_uuid(); kind text not null CHECK in ('contact','corporate','multiday_quote'); email text not null; email_normalized text GENERATED ALWAYS AS (lower(btrim(email))) STORED (index, for Phase 82 erasure); name text; phone text; company text; payload jsonb not null default '{}'; created_at timestamptz not null default now() (index).

EXCEPTION WHEN OTHERS THEN RAISE WARNING 'enqueue_inquiry_lead failed: %', SQLERRM; END; calls `public.outbox_enqueue('lead.inquiry', 'inquiry', NEW.id, 'lead.inquiry:' || NEW.id::text, now())`; RETURN NEW.
