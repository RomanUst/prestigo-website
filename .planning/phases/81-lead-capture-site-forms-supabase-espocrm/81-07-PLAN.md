  6. Contact match (D-11): only when draft.email is non-null: GET `/Contact?select=id&maxSize=1&where[0][type]=equals&where[0][attribute]=emailAddress&where[0][value]=<encoded email>`; hit -> cExistingCustomer true + cExistingContactId; any non-auth error -> no mark; auth error -> propagate.
  7. Success -> complete sent -> outcome sent.
  8. Errors: classifyEspoError transient -> isTerminalAttempt(attempts) ? complete failed '<code>_exhausted' : reschedule(now + nextAttemptDelaySeconds(attempts), code) + publish(delay, dedup `a<attempts>`) -> rescheduled; auth -> reschedule(now + AUTH_BREAKER_SECONDS, 'crm_auth') + publish -> breaker; permanent/not_found on POST -> complete failed code; OutboxStoreError during processing -> best-effort reschedule with backoff code 'db_error'; any other exception -> reschedule with backoff code 'internal_error'. The function itself only throws if the store is unreachable even for the reschedule (route then answers 500 so QStash retries).
