## Trust Boundaries

|----------|-------------|
| GitHub Actions runner -> Anthropic API | the CI job holds and uses the API key |
| CI job -> repository (PR) | the automated job writes files and opens PRs with a scoped token |
| repo secret store -> workflow env | the secret is injected into the job at run time |

| T-72-01 | Information Disclosure | ANTHROPIC_API_KEY leaking via CI logs / PR diff | high | mitigate | Key read only from ${{ secrets.* }}, never echoed; no env-printing run steps; SDK does not echo the key; secret value is never committed (.gitignore already excludes .env*) |
| T-72-03 | Elevation of Privilege | over-broad GITHUB_TOKEN / workflow-injection via untranslated content in PR title/body | high | mitigate | Least-privilege permissions block (contents:write + pull-requests:write only); PR title/body built from a fixed QA summary, not from raw translated content interpolated into shell |
| T-72-08 | Tampering | translations pushed straight to main, bypassing review | medium | mitigate | peter-evans/create-pull-request@v8 opens a PR against main; the workflow never pushes to main directly (D-08) |
