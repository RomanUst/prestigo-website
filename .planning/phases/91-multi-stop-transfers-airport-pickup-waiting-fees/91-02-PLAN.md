<objective>
The server quote prices a transfer through its stops: kilometres through every point from Google Routes, plus paid waiting per class from the admin rate, with no flat per-stop fee and no fixed route price when stops exist.

- export function extraWaitingBlocks(minutes: number): number   // D-16: Math.ceil(minutes / 15), no free deduction
- export function extraWaitingAmountMinor(minutes: number, ratePerBlockEur: number, currency: 'eur' | 'czk'): number   // eur = Math.round(blocks * rate); 'eur' -> eur * 100, 'czk' -> eurToCzk(eur) * 100
