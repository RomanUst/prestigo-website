## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PostgREST (anon / authenticated keys) to the new tables | stop addresses and extra-charge facts are client data and money records |
| erasure request to the new tables | a person's stop addresses and the operator's extra description must go with the person |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-91-01 | Information disclosure | booking_stops, booking_extra_charges via the public API | high | mitigate | REVOKE ALL from anon and authenticated, RLS on with deny policies; text test plus pg_policies in the smoke |
| T-91-02 | Information disclosure | stop addresses and extra descriptions after an erasure | high | mitigate | erasure_anonymise_person copy nulls them; a charging extra blocks the erasure; text test asserts the 088 body is kept whole |

| T-91-04 | Tampering | waiting rate defaulted in the migration (clients charged for waiting the owner never priced) | medium | mitigate | no DEFAULT, no UPDATE; D-05 text test; smoke counts rows with a rate (expects 0) |
