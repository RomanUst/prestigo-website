## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to /api/card-checkout/init, /intent, /api/create-payment-intent | untrusted booking body: coordinates, stops, waits, legacy distanceKm, isAirport, displayed amount |
| server to Google Routes | the distance that decides the price |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-91-12 | Tampering | priceCheckout price inputs (distanceKm, isAirport, amount) | high | mitigate | server route distance and isAirportTrip only; tamper tests store the server distance and answer 409 on a client amount |
| T-91-13 | Tampering | routing outage turned into a cheap booking | high | mitigate | 503 ROUTING_UNAVAILABLE, no fallback; tests on all three routes |
| T-91-14 | Denial of service | stop arrays to burn Google quota or memory | medium | mitigate | max 5 stops, strict stop objects, existing body caps and rate limits (init 30, intent 10, create-payment-intent 10 per minute) |
