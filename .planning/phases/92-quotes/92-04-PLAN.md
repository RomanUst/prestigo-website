<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser and third parties to the quote URL | the token in the path is a bearer secret |
| browser to /api/quote/* | public, token-authenticated, creates Stripe objects |
| Stripe events to the webhook | a quote payment must not be taken for a booking payment |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-92-11 | Information disclosure | token via Referer, analytics, chat, CSP reports | high | mitigate | no-referrer header, PRIVATE_SEGMENTS, SECRET_PATH_RE; tests per surface |
| T-92-12 | Information disclosure | search indexing of a quote | medium | mitigate | X-Robots-Tag and page metadata noindex; robots.txt left without a block so the rule is read |
| T-92-13 | Spoofing | cross-site POST to /api/quote/* | high | mitigate | strict Origin check through the two CSRF lists |
| T-92-14 | Denial of service | Stripe cost abuse and database load on public quote routes | medium | mitigate | per-IP LIMITS keys; a valid token is required in every route |
| T-92-15 | Tampering | deposit PaymentIntent handled by the legacy chain (booking created from metadata) | high | mitigate | card_ prefix kinds; test that classifyPaymentEvent never returns null for them |
| T-92-SC | Tampering | npm/pip/cargo installs | high | accept | Rationale: this plan installs no package and runs no package-manager command |
