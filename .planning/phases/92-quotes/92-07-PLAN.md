| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-92-21 | Elevation of privilege | server-side request forgery from the rendered document | high | mitigate | request interception aborts every non-data: request; test asserts an https request is aborted |
| T-92-22 | Tampering | script in operator or client text runs in the renderer | high | mitigate | JavaScript disabled; values HTML-escaped by the document builder (92-20) |
| T-92-23 | Tampering | Chromium pack swapped at the download URL | medium | accept | Rationale: URL pinned to a versioned release tag over HTTPS; the package is the one Vercel documents; residual risk recorded for the owner (alternative: self-host the pack) |
