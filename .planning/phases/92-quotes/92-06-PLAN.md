<interfaces>
SQL: public.quote_convert_to_bookings(p_quote_id uuid, p_version_id uuid, p_payment_intent_id text, p_customer_id text, p_payment_method_id text, p_lines jsonb, p_actor_type text, p_actor_id text) RETURNS jsonb, LANGUAGE plpgsql SECURITY DEFINER SET search_path = ''.
- p_lines: [{ "position": int, "booking_reference": text, "hold_at": timestamptz-or-null }] — one entry per line position of the version, nothing else is read from it
- returns { "converted": true, "first_time": true|false, "booking_ids": [uuid,...] } or { "converted": false, "reason": "not_found" | "not_accepted" | "version_mismatch" | "intent_mismatch" | "voided" | "cancelled" | "lines_mismatch" | "hold_at_missing" }
- steps: lock quotes row FOR UPDATE; status paid (or paid_at NOT NULL, whatever cancelled_at / voided_at say) -> if p_payment_intent_id = deposit_payment_intent_id: existing booking ids (bookings.quote_id = quote, ordered by the line position) with first_time false, nothing written (W2: a replay of the recorded deposit, also after a later cancel, is never a refund case); otherwise converted false, reason intent_mismatch; else require status accepted, current_version_id = p_version_id, deposit_payment_intent_id = p_payment_intent_id, voided_at and cancelled_at NULL, the version frozen, p_lines positions equal to the version's line positions; for each line in position order insert the booking (status 'confirmed', booking_type 'confirmed', booking_source 'manual', lead_channel from the quote, client name / email / phone from the quote, every trip field of the line including landing triple, coordinates, distance_km, flight_number, terminal, special_requests, extras, amount_eur and amount_czk from the line, locale from the version, cancel_policy and cancel_policy_version from the version, quote_id, quote_line_id, quote_deposit_minor = deposit_share_minor, booking_reference from p_lines, payment columns by mode), then its stops copied from quote_version_line_stops, then PERFORM public.append_payment_event(booking_id, jsonb with key 'quote_deposit:'||p_payment_intent_id, kind 'quote_deposit', stripe_object_id p_payment_intent_id, amount_minor = deposit share, currency, actor), then one booking_payment_consents row (mode 'quote', text and sha256 and version and ip and user agent and locale copied from the quote_acceptances row whose payment_intent_id = p_payment_intent_id); finally update quotes (status 'paid', paid_at now(), stripe_customer_id and stripe_payment_method_id when NULL), set that acceptance's confirmed_at, insert quote_events 'deposit_paid' (key 'deposit_paid:'||pi, amount = version deposit_minor) and 'converted' (key 'converted:'||version id)
- mode by line: remainder_method saved_card and remainder_minor > 0 -> payment_mode 'card_hold', payment_state 'card_saved', payment_amount_minor = remainder_minor, payment_currency = version currency, stripe_customer_id, stripe_payment_method_id, hold_at from p_lines (NULL -> reason hold_at_missing, nothing written); cash and remainder > 0 -> 'cash_guarantee', 'card_saved', same amount and Stripe ids, hold_at NULL; otherwise payment_mode 'quote', payment_state 'none', no Stripe ids, payment_amount_minor NULL. The same table as bookingModeFor in lib/quotes/money.ts.
Fake DB: rpc('quote_convert_to_bookings', args) with the same reasons, the same rows, and the bookings_quote_line_id_key uniqueness.
</interfaces>
