<objective>
Build the first-visit language-suggestion banner (UX-02): a new, crawler-safe client component that suggests a locale switch from the browser's preferred language, never redirects automatically, and remembers a dismissal or a switch via the `NEXT_LOCALE` cookie.

Purpose: UX-02 explicitly forbids any automatic redirect (D-05) and requires the crawler and the user to always see byte-identical HTML (D-04) — this is a genuinely new, client-only component (no existing analog to "replace"), modeled on `CookieBanner.tsx`'s dismiss-once structure and sequenced to never overlap it (UI-SPEC sequencing note).

Output: `components/FirstVisitBanner.tsx`, mounted in `SiteChrome.tsx` after `<CookieBanner />`, new `Common.firstVisitBanner` catalog strings translated into all 6 non-EN locales, and a component test.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser navigator.language/navigator.languages → suggested locale | Client-only read compared against the fixed `routing.locales` allowlist before ever being used as a `router.replace` locale argument |
| FirstVisitBanner "Stay" action → NEXT_LOCALE cookie | The one legitimate hand-rolled `document.cookie` write in the whole i18n surface (RESEARCH Pattern 6) |
| Server-rendered HTML → crawler vs. user | The component's SSR output must never branch on Accept-Language (no cloaking) |
