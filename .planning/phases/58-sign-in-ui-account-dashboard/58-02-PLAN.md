<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client → saved_passengers / customer_profiles rows | Any authenticated user could attempt to read or mutate another user's rows. RLS is the enforcement point. |
| concurrent writers → is_default | Two concurrent "set default" requests could both try to set is_default=true. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-58-03 | Elevation of Privilege (IDOR) | saved_passengers rows | mitigate | Own-row RLS for SELECT/INSERT/UPDATE/DELETE using `(select auth.uid()) = user_id`, mirroring migration 044 (D-07). Cross-user access returns zero rows / is rejected. |
| T-58-04 | Tampering | is_default uniqueness | mitigate | Partial unique index `WHERE is_default = true` enforces single default atomically at the DB layer — no app-logic race window (RESEARCH Pitfall 3 / Pattern 5). |
| T-58-05 | Information Disclosure | customer_profiles new columns (phone, ico, vat_id) | mitigate | Existing 044 SELECT policy already scopes reads to own row; no new policy weakens it; new columns inherit it. |
| T-58-06 | Denial of Service | orphaned passenger rows | accept | user_id FK ON DELETE CASCADE removes passengers when the auth user is deleted; low-value target, no further mitigation. |
| T-58-SC | Tampering | npm/pip/cargo installs | accept | No package installs — RESEARCH Package Legitimacy Audit confirms zero new packages. (`npx supabase` is invoked as a tool, not added as a dependency.) |
</threat_model>
