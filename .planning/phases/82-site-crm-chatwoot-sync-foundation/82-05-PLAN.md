- public.identity_normalize_phone(p_raw text) RETURNS text LANGUAGE plpgsql IMMUTABLE SET search_path = '' — the port above (translate() for the four digit blocks; regexp_replace for marks, dashes and separators); REVOKE EXECUTE FROM PUBLIC, anon, authenticated; GRANT to service_role.
- CREATE OR REPLACE public.identity_resolve_core(p_email_raw text, p_phone_raw text, p_basis text, p_user_id uuid) RETURNS TABLE(identity_id uuid, outcome text), same signature and SECURITY/search_path as 069, re-REVOKE (CREATE OR REPLACE keeps grants, the REVOKE line is still written so the test pattern holds). Rules, e = normalised email, p = identity_normalize_phone(p_phone_raw), shared(p) = phone_flags row with shared = true:
  1. e NULL -> (NULL, 'no_identity').
  2. I owns e: I.erasing_at set -> (I, 'erasing'). Attach p_user_id when I.user_id is NULL. If p not NULL and not shared: when another non-erasing identity owns p -> INSERT phone_flags(p, true, 'auto') ON CONFLICT DO NOTHING; else upsert identity_phones(I, p). -> (I, 'resolved').
  3. e new and p_user_id has an identity J -> identity_emails(e, J, 'signup'); phone handled as in rule 2 for J -> (J, 'resolved').
  4. e new, p not NULL, not shared, exactly one identity J owns p, J.erasing_at NULL, and NOT (p_user_id NOT NULL AND J.user_id NOT NULL AND J.user_id <> p_user_id) -> identity_emails(e, J, basis 'phone', via_phone p); INSERT phone_flags(p, true, 'auto') ON CONFLICT DO NOTHING -> (J, 'resolved').
  5. Otherwise create identity N (user_id = p_user_id) with identity_emails(e, N, p_basis); if p not NULL and not shared: owned by a non-erasing identity (signup-guard case) -> flag shared 'auto'; owned only by an erasing identity -> ignore p; unowned -> identity_phones(N, p). -> (N, 'resolved').
