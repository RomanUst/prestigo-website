Output: migration 075 (applied live by the orchestrator), erasure store + saga, router branch, EspoCRM role change (config-as-code), tests. The admin preview/confirm UI and routes are plan 82-13.

- table public.erasure_requests: id uuid PK DEFAULT gen_random_uuid(); requested_by uuid NOT NULL; email_hmac text NOT NULL CHECK (email_hmac ~ '^[0-9a-f]{64}$'); identity_id uuid; user_id uuid; booking_ids uuid[] NOT NULL DEFAULT '{}'; inquiry_ids uuid[] NOT NULL DEFAULT '{}'; subject_emails text[] NOT NULL DEFAULT '{}'; subject_phones text[] NOT NULL DEFAULT '{}'; status text NOT NULL CHECK (status IN ('previewed','confirmed','running','completed','failed')); expires_at timestamptz NOT NULL; requested_at timestamptz NOT NULL DEFAULT now(); confirmed_at, completed_at timestamptz; steps jsonb NOT NULL DEFAULT '{}'; counts jsonb NOT NULL DEFAULT '{}'; verified boolean. RLS deny-all + REVOKE ALL from anon, authenticated.
- public.erasure_scope(p_email text, p_phone text) RETURNS jsonb (Supabase-only preview data): outcomes 'invalid' | 'shared_phone' (with identities count) | 'not_found' | 'already_in_progress' | 'ok' with { primary_email, emails, phones (non-shared), identity_id, user_id, booking_ids (not yet anonymised: booking_identity of the identity ∪ bookings whose normalised client_email is one of the emails ∪ bookings of the user), inquiry_ids (inquiries by normalised email), counts { bookings, upcoming (pickup_utc >= now() and not cancelled), inquiries, quote_leads, has_account } }. A phone search resolves only through a non-shared identity phone.
- public.erasure_preview_create(p_actor uuid, p_email_hmac text, p_scope jsonb, p_ttl_seconds integer) RETURNS uuid: inserts status 'previewed' with ids, subject emails/phones and counts (the preview counts, incl. upcoming) from the scope, expires_at now() + least(greatest(p_ttl_seconds, 60), 3600) seconds.
- public.erasure_confirm(p_request_id uuid, p_actor uuid) RETURNS text: row FOR UPDATE; 'not_found'; status confirmed/running -> 'already_in_progress'; status other than previewed -> 'not_previewed'; expires_at passed -> 'expired'; requested_by <> p_actor -> 'actor_mismatch'; take the identity lock; set status confirmed, confirmed_at now(); set contact_identities.erasing_at = now() for identity_id; outbox_enqueue('erase.person', 'person', COALESCE(identity_id, id), 'erase.person:' || id, now()); a unique-index violation -> 'already_in_progress'; else 'confirmed'.
- public.erasure_load(p_request_id uuid) RETURNS jsonb: { id, status, requested_by, email_hmac, expires_at, identity: { id, espo_contact_id, chatwoot_contact_id, user_id } or null, user_id, emails, phones, booking_ids, inquiry_ids, counts, steps } (the 82-13 confirm route reads email_hmac, expires_at and counts.upcoming from it; the saga reads the rest).
- public.erasure_record_step(p_request_id uuid, p_step text, p_result jsonb) RETURNS void: p_step in ('chatwoot','espocrm','verify','supabase','auth'); steps := steps || jsonb_build_object(p_step, p_result || {done_at}); status 'running' when it was confirmed.
- public.erasure_anonymise_person(p_request_id uuid) RETURNS jsonb counts: identity lock; anonymise bookings in booking_ids (D-08, set anonymised_at); scrub the residual tables for those bookings and emails; DELETE inquiries (inquiry_ids or email match) and quote_leads (email match); DELETE contact_identities row (cascades emails/phones/booking_identity); DELETE phone_flags rows for subject_phones with source 'auto' that no other identity holds; return { bookings_anonymised, inquiries_deleted, quote_leads_deleted, audit_values_scrubbed, email_log_scrubbed, gnet_payloads_scrubbed, trip_notes_scrubbed, identity_deleted }.
- public.erasure_complete(p_request_id uuid, p_verified boolean, p_counts jsonb, p_status text) RETURNS void: status completed|failed, completed_at, counts, verified; clears identity_id, user_id, booking_ids, inquiry_ids, subject_emails, subject_phones.
- public.erasure_log(p_limit integer) RETURNS TABLE(id uuid, reference text, status text, requested_at timestamptz, completed_at timestamptz, steps jsonb, verified boolean): reference = left(email_hmac, 10); newest first; cap 100.
