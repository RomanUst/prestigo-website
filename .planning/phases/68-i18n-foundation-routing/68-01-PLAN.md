## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → middleware | Untrusted request pathname (incl. attacker-chosen locale prefix) crosses into the composed CSP/Supabase/CSRF chain |
| middleware → App Router | next-intl rewrite (x-middleware-rewrite) determines which `[locale]`/`(internal)` segment renders |
| client → /api (mutations) | Cross-origin state-changing requests reach CSRF-protected endpoints |
