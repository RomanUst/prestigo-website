## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet -> /api/webhooks/chatwoot | anyone can POST; only an HMAC-valid request may reach classification and the database |
| Chatwoot contact data -> classifier | operator- or site-written values decide whether a row is enqueued |
| receiver -> Vercel logs | every request writes one line; must never carry customer data |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-83-52 | Denial of Service | contact_updated echo / feedback storm (site write -> Chatwoot -> webhook -> site) | high | mitigate | isSiteEcho drop before the RPC + contact fuseLimit 20 per 10 min -> fused, no publish, one ALERT line (Task 1 tests); RPC fuse from 83-01 (T-83-06) |

| T-83-56 | Denial of Service | malformed signature or timestamp throwing a 500 instead of failing closed | low | mitigate | verify matrix: short signature -> bad_signature without throw, non-numeric or missing timestamp -> malformed (Task 3) |
