Migration 077 contract (`supabase/migrations/077_identity_chat.sql`):
- Basis CHECK: a DO block loops over pg_constraint rows with conrelid = 'public.identity_emails'::regclass, contype = 'c' and pg_get_constraintdef(oid) containing 'basis', and EXECUTEs `ALTER TABLE public.identity_emails DROP CONSTRAINT <name>` (format with %I); then `ALTER TABLE public.identity_emails ADD CONSTRAINT identity_emails_basis_check CHECK (basis IN ('email', 'phone', 'signup', 'split', 'chat'))`.
- `public.identity_chat_lookup(p_email_raw text) RETURNS TABLE(identity_id uuid, customer boolean, erasing boolean, espo_contact_id text, chatwoot_contact_id bigint)`: STABLE, no writes; zero rows when the email does not normalise or has no owner.
- `public.identity_by_chatwoot_contact(p_contact_id bigint) RETURNS TABLE(identity_id uuid, customer boolean, erasing boolean, espo_contact_id text, emails text[])`: STABLE; at most 2 rows ordered by created_at (2 rows = ambiguous for the caller).
- `public.identity_resolve_chat(p_email_raw text, p_phone_raw text) RETURNS TABLE(identity_id uuid, outcome text, customer boolean)`: `PERFORM pg_advisory_xact_lock(hashtextextended('identity', 0))`; core(p_email_raw, p_phone_raw, 'chat', NULL); customer computed for the returned identity (false when NULL).
- `public.identity_attach_chat_contact(p_identity_id uuid, p_email_raw text, p_phone_raw text) RETURNS TABLE(email_outcome text, phone_outcome text)`: same global lock; identity missing -> ('identity_missing','identity_missing'); erasing -> ('erasing','erasing'); email: not usable -> 'none', owned by p_identity_id -> 'unchanged', owned by another identity -> 'owned_elsewhere', else INSERT (email, p_identity_id, 'chat') -> 'attached'; phone: not usable -> 'none', flagged shared -> 'shared', in identity_phones of another live identity -> 'owned_elsewhere', already this identity's -> 'unchanged', else INSERT identity_phones -> 'attached'. Bumps contact_identities.updated_at when anything was attached.
- `public.identity_phone_usable(p_phone_raw text) RETURNS text`: identity_normalize_phone result, or NULL when NULL or flagged shared.
- "customer" everywhere = `c.user_id IS NOT NULL OR EXISTS (SELECT 1 FROM public.booking_identity b WHERE b.identity_id = c.id)`.
- All: SECURITY DEFINER, `SET search_path = ''`, schema-qualified names, REVOKE EXECUTE FROM PUBLIC, anon, authenticated, GRANT EXECUTE TO service_role.
