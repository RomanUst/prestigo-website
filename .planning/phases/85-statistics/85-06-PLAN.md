| T-85-20 | Tampering (XSS / injection) | email deep link value | medium | mitigate | strict reference-or-email allowlist (no whitespace, angle brackets, quotes, backtick), length cap 254; value only rendered as an input value and sent as a bound query parameter; tests for hostile values |
