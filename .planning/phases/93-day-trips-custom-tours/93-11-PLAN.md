| admin-authored tour content to public HTML and JSON-LD | content is operator input rendered to every visitor |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-93-29 | Tampering | stored XSS through tour text in JSON-LD | high | mitigate | safeJsonLd escapes <, U+2028/9; test with a script-breaking payload; all other text rendered as React text |
| T-93-30 | Spoofing | open redirect via slug / locale | medium | mitigate | redirect only after a DB hit for a slug matching TOUR_SLUG_PATTERN; target built with getPathname for locale 'en' |
| T-93-31 | Information disclosure | draft or incomplete content | medium | mitigate | page reads only published tours and complete translations (store readers); incomplete locale redirects; hreflang lists only complete locales |
| T-93-32 | Repudiation | stale or typed prices in structured data | medium | mitigate | Offer prices from the DB row; admin writes revalidate; snapshot test normalizes priceValidUntil |
| T-93-SC | Tampering | npm/pip/cargo installs | high | accept | Rationale: this plan installs no package and runs no package-manager command |
