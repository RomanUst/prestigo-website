Hostinger DNS API (project memory, used before on this domain):
- Base: https://developers.hostinger.com/api/dns/v1/zones/rideprestigo.com with header Authorization: Bearer TOKEN.
- GET returns an array of {name, type, ttl, records: [{content, is_disabled}]}.
- PUT body {overwrite: true|false, zone: [{name, type, ttl, records: [{content}]}]} upserts per name+type. A CNAME cannot coexist with another type on the same name.
- Known records that must stay untouched: apex A 216.198.79.1 (Vercel, single A, no AAAA), www CNAME cname.vercel-dns.com., MX mx1/mx2.hostinger.com, SPF include _spf.mail.hostinger.com, DKIM hostingermail-a/b/c._domainkey, DMARC, autodiscover/autoconfig.
- Authoritative NS: ns1.dns-parking.com, ns2.dns-parking.com.

Env files written here (host contract; values never in git):

- restic's docs recommend B2 through its S3-compatible API (native b2: backend has error-handling issues) - hence s3: URLs and AWS_* variable names.
