<interfaces>
Healthchecks.io API v3 (header X-Api-Key, project read-write key):
- POST https://healthchecks.io/api/v3/checks/ with JSON {name, tags, desc, timeout, grace, channels: "*", unique: ["name"]} - idempotent by name; response includes ping_url.
- GET https://healthchecks.io/api/v3/checks/ lists checks with status (new, up, grace, down, paused).
- GET https://healthchecks.io/api/v3/channels/ lists integrations (kind email, telegram).
- Ping protocol: PING_URL (success), PING_URL/start, PING_URL/fail; POST body shows in the event log.

UptimeRobot API v2 (form-encoded, api_key + format=json; if v2 answers with a deprecation error, use the documented v3 equivalents):
- POST https://api.uptimerobot.com/v2/getAlertContacts, /v2/getMonitors, /v2/newMonitor (type 2 = keyword, keyword_type 2 = alert when the keyword does NOT exist, keyword_value, interval 300, alert_contacts "ID_0_0-ID_0_0").
- Monitor status 2 = up, 8 = seems down, 9 = down.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-76-25 | Denial of Service | alert path | high | mitigate | primary signals come from UptimeRobot and Healthchecks (external); a dead VPS stops pings, which itself alerts after the grace period (D-01, Pitfall 13) |
| T-76-26 | Spoofing | Healthchecks ping URLs | medium | mitigate | URLs only in root 0600 monitor.env (and the encrypted backup); never committed or echoed; forged success pings require host or backup compromise |
| T-76-27 | Information Disclosure | UptimeRobot / Healthchecks API keys | medium | mitigate | read only from env vars of single commands, never written to disk/repo; literal-key grep gate on the committed files |
| T-76-28 | Repudiation | silent worker death (Sidekiq, EspoCRM daemon, MariaDB) | high | mitigate | heartbeat-based Sidekiq check and daemon/DB check every 5 minutes with fail pings (D-04d) |
| T-76-SC | Tampering | npm/pip/cargo installs | high | mitigate | no package installs (bash, curl, jq, openssl, redis-cli inside the pinned image); package-legitimacy gate not triggered |
