<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| panel API JSON -> rendered DOM | customer-supplied text (addresses, notes) and links cross into the operator's browser |
| iframe -> operator clipboard | the payment link is copied for pasting into a customer reply |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-84-34 | Tampering | XSS through notes, addresses or names | medium | mitigate | text rendering only, no HTML-injection prop (test greps the component source), nonce CSP |
| T-84-35 | Tampering | operator pastes a malicious "payment link" to a customer | medium | mitigate | Copy button only for https buy.stripe.com links, re-checked on the client after the server check |
| T-84-36 | Information Disclosure | operator shares history of an unverified contact | medium | mitigate | prominent unverified hint above the counters; runbook guidance (84-06) |
| T-84-SC | Tampering | npm/pip/cargo installs | high | mitigate | no package installs in this plan |
</threat_model>
