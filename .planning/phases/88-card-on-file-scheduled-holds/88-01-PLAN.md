- async applyTransition(args: { bookingId: string; from: PaymentState[]; to: PaymentState; patch?: PaymentPatch; event: LedgerEvent }): Promise<{ applied: boolean; duplicate?: boolean; currentState?: PaymentState; booking?: Record<string, unknown> }> — throws Error('illegal payment transition') before any query when isLegalTransition is false; throws Error('payment transition failed') on an RPC error or a malformed result
- async appendPaymentEvent(bookingId: string, event: LedgerEvent): Promise<{ inserted: boolean }>
- async claimDueHolds(limit: number, leaseSeconds: number): Promise<Record<string, unknown>[]>

TRANSITIONS (from -> allowed to). Self-loops exist for edit re-evaluation and checkout re-submit only.
- none -> checkout_pending
- checkout_pending -> checkout_pending, card_saved, authorized, released
- card_saved -> card_saved, placing_hold, capturing, released
- placing_hold -> authorized, card_saved, failed, placing_hold
- authorized -> authorized, card_saved, expired, capturing, released
- capturing -> captured, balance_due, failed, capturing
- balance_due -> balance_due, captured, released
- failed -> failed, placing_hold, capturing, captured, released
- expired -> expired, placing_hold, capturing, released
- captured -> (none)    released -> (none)
