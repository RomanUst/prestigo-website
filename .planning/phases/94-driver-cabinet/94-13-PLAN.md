## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser permission -> push subscription | the browser owns permission; the server stores only endpoint and keys for the session driver |
| server -> page | only the VAPID public key reaches the browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-94-59 | Information disclosure | VAPID private key reaching the client bundle | high | mitigate | client modules import nothing from the server push module and never name the private key (grep gate); the page passes only vapidPublicKey() |
| T-94-60 | Spoofing | a subscription stored for the wrong driver | medium | mitigate | the route takes driver_id from the session (94-05); 401 sends the driver to sign-in |
| T-94-61 | Elevation of privilege | worker registered with a wider scope | medium | mitigate | register('/driver/sw.js', { scope: '/driver/' }) only; no scope-widening header (94-08) |
| T-94-62 | Denial of service | permission prompt fatigue / auto prompts | low | mitigate | requestPermission only inside the switch tap; the hint never prompts (gate) |
| T-94-SC | Tampering | npm/pip/cargo installs | high | accept | Rationale: this plan installs no package |
</threat_model>
