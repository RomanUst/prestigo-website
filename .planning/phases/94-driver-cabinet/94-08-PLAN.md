<objective>
The cabinet becomes a Home Screen web app that can show push notifications: a /driver/-scoped manifest with brand icons, a static service worker, cabinet-only metadata, and the CSP / header changes the worker needs.

Purpose: D-09 (PWA on Android and iOS 16.4+). DCAB-12, DCAB-13.
Output: manifest, service worker, icons (rendered by a committed script), layout metadata, worker-src in the nonce CSP, sw.js / manifest headers.

Design choice (Claude's discretion, D-09 stack): the manifest is a static file at public/driver/manifest.webmanifest (no route handler: the content is static and a route folder named like a metadata file risks the Next metadata convention); the colour literal #EFE8DA lives only there and in the icon sources under scripts/, both outside the colour-guard roots. Middleware already lets /driver/*.webmanifest, /driver/*.js and /driver/icons/*.png through (the matcher does not exclude driver/ paths, research Pitfall 9) — do not touch the matcher.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| push service -> service worker | payload content is attacker-influenced only through our own server, but the worker treats it as untrusted |
| service worker scope -> site | a worker controls every page under its scope |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-94-38 | Elevation of privilege | service worker scope escalation | high | mitigate | worker at /driver/sw.js (default scope /driver/), no Service-Worker-Allowed header (gate), no fetch handler, so it cannot intercept /admin or public pages |
| T-94-39 | Tampering | open redirect through the notification url | medium | mitigate | url accepted only when it starts with /driver/, else /driver/offers (vm test) |
| T-94-40 | Tampering | script injection into the worker | medium | mitigate | static file, no importScripts / eval (gate), served no-store so a fix ships on the next load |
| T-94-41 | Elevation of privilege | CSP weakening | medium | mitigate | only worker-src 'self' is added to the nonce policies; static policy, matcher and other directives pinned by existing tests |
| T-94-SC | Tampering | npm/pip/cargo installs | high | accept | Rationale: this plan installs no package (sharp is already present via next and used by scripts/convert-images.mjs) |
</threat_model>
