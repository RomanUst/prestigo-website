## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| phone browser -> /api/driver/cabinet/request-code, /verify | untrusted email and code input, unauthenticated callers |
| PostgREST (anon / authenticated keys) -> new driver tables | codes, sessions and push keys must never be readable from the browser |
| driver cookie -> server | the opaque token is the only credential; stored hashed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-94-01 | Spoofing | verify route / consume_driver_login_code | high | mitigate | CSPRNG 6-digit code, 5 attempts per code counted inside the RPC under FOR UPDATE, 10-minute expiry, single use, a new request kills older codes, per-IP verify limit fail-closed |
| T-94-02 | Information disclosure | request-code route | medium | mitigate | identical 200 body for unknown / not-invited / disabled emails, no row, no email; code email sent in after() so timing does not depend on existence; no email logged |
| T-94-03 | Denial of service | request-code (mail bombing one inbox) | medium | mitigate | per-hashed-email limit 3 per 10 min plus per-IP 5/min, both fail-closed |
| T-94-04 | Spoofing | session cookie | high | mitigate | 256-bit random token, sha256 at rest, httpOnly, Secure in production, SameSite=Lax, fresh token on every sign-in (no fixation), absolute 30-day expiry |
| T-94-05 | Elevation of privilege | disabled driver with an open session | high | mitigate | getDriverSession joins drivers.cabinet_enabled on every call; test proves the same cookie fails right after disable |
| T-94-06 | Elevation of privilege | identity mixing with customer / admin (D-07) | high | mitigate | no Supabase Auth user, separate cookie name, source gate that the auth module and routes never import the Supabase-Auth cookie helpers |
| T-94-07 | Information disclosure | driver_login_codes / driver_sessions / driver_push_subscriptions via the public API | high | mitigate | REVOKE ALL from anon and authenticated, RLS on with USING (false) / WITH CHECK (false); smoke checks has_table_privilege false |
| T-94-08 | Tampering | cross-site POST to cabinet routes | medium | mitigate | '/api/driver/cabinet' in CSRF_PROTECTED_PREFIXES and CSRF_STRICT_ORIGIN_REQUIRED (missing Origin rejected) |
| T-94-SC | Tampering | npm/pip/cargo installs | high | accept | Rationale: this plan installs no package and runs no package-manager command |
