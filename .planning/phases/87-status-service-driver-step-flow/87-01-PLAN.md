<interfaces>
Contracts this plan creates. Later plans extend them (87-03 adds compare-and-set and `expectedFrom`; 87-07 changes the inside of pushGnetForTransition); keep the names.

lib/booking-status-service.ts (server-only module; imports createSupabaseServiceClient, after, logEmail, the status email senders, scheduleQStashReminder, deactivateBookingPaymentLink, VALID_TRANSITIONS, pushGnetForTransition)
- type StatusActor = { type: 'admin'; id: string | null } | { type: 'driver'; id: string } | { type: 'system'; id: string }
- type StatusSideEffectProfile = 'full' | 'cancel-route' | 'assign-route'
- interface AdvanceBookingStatusInput { bookingId: string; to: string; actor: StatusActor; source: string; profile: StatusSideEffectProfile; current?: Record<string, unknown>; patch?: { operator_notes?: string; driver_price_czk?: number | null; driver_id?: string } }
  - `current`: a row the caller already read; when present the service skips its own select (keeps the cancel/assign call order identical to today)
  - `source` values used in this phase: 'admin_patch', 'admin_cancel', 'admin_assign', 'driver_trip', 'admin_no_show'
- type AdvanceBookingStatusResult =
  | { ok: true; applied: true; previous: string; current: string; booking: Record<string, unknown> }
  | { ok: false; code: 'not_found' | 'invalid_transition' | 'conflict' | 'db_error'; message: string; currentStatus?: string }
  (the 'conflict' code is declared now and first produced by plan 87-03)
- async function advanceBookingStatus(input: AdvanceBookingStatusInput): Promise<AdvanceBookingStatusResult>
- function advanceResultToResponse(result): NextResponse | null — null when ok; not_found -> 404 { error: 'Booking not found' }; invalid_transition -> 422 { error: result.message }; conflict -> 409 { error: 'status_conflict', currentStatus }; db_error -> 500 { error: 'DB update failed' }

lib/gnet-push.ts
- async function pushGnetForTransition(input: { bookingId: string; bookingSource: string | null; status: string; amountEur: unknown; logTag: string }): Promise<void>
  - returns without any query when bookingSource is not 'gnet' or prestigoToGnetStatus(status) is null
  - otherwise exactly today's code: select gnet_bookings id, gnet_res_no by booking_id (single); missing row -> console.error(`${logTag} no gnet_bookings row for`, bookingId) and return; pushGnetStatus(res_no, mapped, Number(amountEur).toFixed(2)) in try/catch; then update gnet_bookings { last_push_status, last_push_error, last_pushed_at } by id; audit failure logged
  - logTag is '[gnet-status-push]' for the service 'full' profile and '[assign:gnet-push]' for 'assign-route' (today's two console prefixes)
