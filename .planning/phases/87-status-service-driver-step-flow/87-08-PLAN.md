lib/driver-trip-step.ts (server-only)
- driverTripRequestSchema = z.union([z.object({ step: z.enum(DRIVER_STEPS) }).strict(), z.object({ note: z.string().max(2000) }).strict()]) (plan 87-09 adds a third strict member { action: 'request_no_show' })
- interface DriverTripRecord { assignmentId: string; assignmentDriverId: string; assignmentStatus: string | null; booking: { id: string; status: string; driver_id: string | null; booking_source: string | null; amount_eur: unknown; pickup_utc: string | null; pickup_date: string; pickup_time: string; origin_lat: number | null; origin_lng: number | null; origin_address: string | null; completed_at: string | null; no_show_requested_at: string | null } }
- loadDriverTripForStep(supabase, token): Promise<DriverTripRecord | null> — one select on driver_assignments by trip_token with bookings!inner(...) (read-only; never an update of bookings)
- identity rule: booking.driver_id !== null AND assignmentDriverId === booking.driver_id AND assignmentStatus !== 'declined', else the route answers 400 { error: 'invalid_token' }
- interface TripStepResponse { ok: boolean; status: string; nextStep: DriverStep | null; replay?: boolean; unlocksAt?: string; completedAt?: string; error?: 'step_conflict' | 'too_early' | 'update_failed' }
- driverTripStep({ supabase, trip, step, nowMs, gate? }): Promise<{ httpStatus: 200 | 400 | 409 | 500; body: TripStepResponse | { error: 'invalid_token' } }> — order: replay check, terminal -> 400 invalid_token, nextStep check -> 409 step_conflict, en_route start gate -> 409 too_early, advanceBookingStatus, conflict -> 409 step_conflict with the winner's status, ok -> trip_progress mirror + 200
- driverTripNote({ supabase, trip, note }): Promise<{ httpStatus: 200 | 400 | 500; body }> — active links only
- buildTripView({ booking, nowMs, gate? }): Promise<{ status: string; nextStep: DriverStep | null; lockReason: 'too_early' | 'waiting' | null; unlocksAt: string | null }> — 'waiting' for confirmed, pending, unpaid; 'too_early' when nextStep is en_route and the gate is closed

- fallbackTravelMinutes(km) = Math.ceil(km * 1.4 / 45 * 60)
- travelMinutesFromCentre(origin, opts?): Promise<number> — 0 for null origin or within the radius; else Routes API computeRoutes (same endpoint, key handling and field-mask style as app/api/calculate-price/route.ts ~239-291, field mask routes.duration, 3 s timeout), parse "<n>s", ceil to minutes, cap 240; any failure -> fallback; module-level Map cache keyed bookingId:lat:lng, at most 500 entries

HTTP contract for 87-10/87-11 (response bodies above): 200 step applied or replay; 400 { error: 'invalid_token' } | { error: 'Invalid payload' } | { error: 'Invalid JSON' }; 409 step_conflict | too_early; 429 { error: 'Too many requests' }; 500 update_failed.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| driver phone (bearer trip token in URL) -> /api/driver/trip/{token}/progress | unauthenticated, token-gated write that now changes bookings.status |
| server -> Google Routes API | outbound call with the server Maps key |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-87-22 | Spoofing | leaked or forwarded trip link drives status | high | mitigate | live identity check (driver match, not declined, not ended), strict next-step order, start gate, CAS, operator-only no_show, no amount input; rate limit 20/min/IP |
| T-87-23 | Tampering | skipped / replayed / double-tapped steps | high | mitigate | step === nextStepFor(status) or 409; replay returns 200 with no write; CAS expectedFrom (tests) |
| T-87-24 | Tampering | mass assignment through the request body | high | mitigate | zod .strict() union of { step } / { note }; amount, status and extra keys -> 400 (tests) |
| T-87-25 | Information Disclosure | token enumeration | medium | mitigate | uuid shape check before DB; uniform 400 invalid_token for every bad-token reason; rate limit before lookup |
| T-87-26 | Elevation of Privilege | CSRF / limiter silently off | medium | mitigate | path kept under /api/driver/trip (middleware prefix) and literal LIMITS key; both asserted in tests/driver-trip-progress.test.ts |
| T-87-27 | Denial of Service | Maps outage blocks drivers | medium | mitigate | 3 s timeout, haversine fallback, null pickup -> open gate; Maps called only while the next step is en_route, cached per booking |
| T-87-SC | Tampering | npm/pip/cargo installs | high | mitigate | no package installs (RESEARCH Package Legitimacy Audit: none); any install attempt is out of scope and must stop for a blocking human checkpoint |
