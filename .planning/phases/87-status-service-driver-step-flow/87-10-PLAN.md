| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

| T-87-34 | Information Disclosure | search indexing of trip links | medium | mitigate | metadata robots index/follow false kept and tested |
| T-87-35 | Tampering | accidental or repeated step submission | medium | mitigate | dialog confirmation before any request, submitting state ignores input, server replay/CAS (87-08) |
| T-87-36 | Tampering | client trusts its own status | low | mitigate | status shown only from server responses / router.refresh, never optimistic |
| T-87-SC | Tampering | npm/pip/cargo installs | high | mitigate | no package installs (RESEARCH Package Legitimacy Audit: none; no slider library); any install attempt is out of scope and must stop for a blocking human checkpoint |
