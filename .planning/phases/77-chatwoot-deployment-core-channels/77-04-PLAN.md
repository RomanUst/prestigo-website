<interfaces>
CLI (argparse, base URL positional, default https://rideprestigo.com; exit 0 clean, 1 findings, 2 infrastructure error, 3 launcher not found when a mode needs it):
- --cwv-capture BASE -> writes scripts/qa/baselines/cwv_chat_baseline.json: { "capturedAt": ISO, "base": BASE, "profile": {...}, "thresholds": { "lcp_pct": 0.10, "lcp_ms": 150, "tbt_pct": 0.10, "tbt_ms": 50, "cls_abs": 0.02, "launcher_inp_ms": 200 }, "pages": { "/": { "lcp_ms", "cls", "tbt_ms", "runs": [...] }, "/routes/prague-vienna": {...}, "/book": {...} } }
- --cwv-compare BASE -> same measurement; also, when the launcher exists, clicks it once per run and records launcher_inp_ms (max event-timing duration of pointerdown/pointerup/click with durationThreshold 16); prints a table page | metric | before | after | limit | OK/REGRESSION; exit 1 on any REGRESSION
- --consent BASE [--expect-launcher] [--locales en,ru,...] [--pages /,/routes/prague-vienna,/book] -> per locale x page: zero requests whose hostname is the chat subdomain of rideprestigo.com, zero cookies named cw_*, zero localStorage keys starting with cw_ or chatwoot; with --expect-launcher also: exactly one button with aria-expanded="false" and aria-controls, and for ar the launcher's center x is left of the viewport middle (bottom-start under dir=rtl), for other locales right of it
- --click BASE [--locales en,ar] [--pages /,/routes/prague-vienna,/book] -> opens the launcher, clicks the first menu item (Chat on site), waits up to 15 s for an iframe whose src host is the chat subdomain; collects securitypolicyviolation events (listener installed via add_init_script into window.__cspViolations) and console messages containing "Content Security Policy"; asserts no chat-host request happened before the click timestamp; exit 1 on any violation or missing iframe, exit 3 when no launcher exists. The real widget only runs against production (the Website inbox restricts allowed domains to rideprestigo.com), so this mode is exercised on production in plan 77-12
- --overlap BASE [--pages /book,/] -> at 375x812 compares the launcher rect with every other visible element whose computed position is fixed or sticky (excluding the launcher subtree and hidden elements); exit 1 on any intersection
Page URLs for locale L: en at /<path>, others at /<L>/<path> (as-needed prefix; / for en home, /ru for ru home).
The chat host is referenced only inside this script (scripts/qa is outside the isolation guard's scan set).
</interfaces>
