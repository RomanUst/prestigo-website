<interfaces>
Template file schema (locked; plans 78-08 and 78-10 write files in this shape) — infra/chatwoot/whatsapp-templates/<key>.json:
- key: kebab-case, equals the filename stem
- name: Meta template name, /^[a-z0-9_]{1,512}$/, prefix prestigo_
- category: "UTILITY" or "MARKETING"
- parameterFormat: "NAMED"
- sourceCanned: canned-response topic the wording comes from, or null
- variables: [{ name: /^[a-z][a-z0-9_]*$/, example: non-empty synthetic string }] in order of first appearance in the en body
- buttons: [] or entries { type: "QUICK_REPLY", textKey } / { type: "URL", textKey, url } (static https URL, no variable)
- header: null (reserved; plan 78-10 may set { format: "DOCUMENT" } only if the owner picks it at the D-10 checkpoint)
- locales: exactly en, ru, es, fr, ar, hi, zh — each { language, body, buttons: { <textKey>: label } }; language is the Meta code: zh -> "zh_CN", every other site locale -> same code

Validation rules (validateTemplate returns a list of human-readable errors; empty list = valid):
- schema fields above; key equals filename stem (loadTemplates checks); exactly the 7 locales; language mapping exact
- body length <= 1024, button label <= 25, name <= 512, all measured with String.length
- quick replies <= 10, URL buttons <= 2, quick replies contiguous (not interleaved with URL buttons); URL buttons https with host in rideprestigo.com, www.rideprestigo.com or g.page and no "{{"
- in every locale body: each declared variable appears at least once as {{name}}; no undeclared {{...}}; the trimmed body neither starts nor ends with a variable
- every locale defines a non-empty label for every button textKey
- header must be null or { format: "DOCUMENT" }

Graph create body (buildCreateBody(template, siteLocale)):
{ name, language, category, parameter_format: "NAMED", components: [ optional { type: "HEADER", format: "DOCUMENT", example: { header_handle: [...] } } only when header is set, { type: "BODY", text, example: { body_text_named_params: [{ param_name, example }...] } }, optional { type: "BUTTONS", buttons: [ { type: "QUICK_REPLY", text } | { type: "URL", text, url } ] } ] }

Graph endpoints (base https://graph.facebook.com/<META_WA_GRAPH_VERSION or v25.0>):
- GET /{WABA}/message_templates?fields=id,name,language,status,category,components,rejected_reason&limit=100[&after=<cursor>] — paging by paging.cursors.after only (never follow paging.next URLs), max 50 pages
- POST /{WABA}/message_templates — create
- POST /{TEMPLATE_ID} — edit (components only)

CLI output contract: one line per name+language: "create", "unchanged", "resubmit", "drift <fields>", "edit", "exists", or with --dry-run "plan <action>"; then "summary: create=N unchanged=N resubmit=N drift=N edit=N exists=N". --status prints "status <name> <language> <STATUS> <CATEGORY>" lines, rejected_reason for REJECTED, and "status_summary approved=N pending=N rejected=N paused=N other=N". --validate prints "valid <name> <language> body_chars=<n>" lines and "validated=<N>".
Rate-limit signals: HTTP 429, or error.code 4, 80007, 130429 or 613 [ASSUMED A5]. Already-exists signal: HTTP 400 whose error message matches /already exists/i or error_subcode 2388024 [ASSUMED].
