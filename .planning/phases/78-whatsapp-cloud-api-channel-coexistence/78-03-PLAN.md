<interfaces>
Template file contract (produced by plans 78-02/78-07): { key, name, category, parameterFormat: "NAMED", sourceCanned, variables: [{name, example}], buttons: [{type: "QUICK_REPLY", id} | {type: "URL", id, url, example?}], locales: { <site locale>: { language, body, buttons: { <id>: text } } } }; LOCALE_TO_META = { en: en, ru: ru, es: es, fr: fr, ar: ar, hi: hi, zh: zh_CN }.

Payload per locale (RESEARCH "Template creation request"; POST https://graph.facebook.com/v25.0/{WABA_ID}/message_templates):
{ name, language, category, parameter_format: "NAMED", components: [
  { type: "BODY", text, example: { body_text_named_params: [ { param_name, example } ] } }   (example only when variables exist),
  { type: "BUTTONS", buttons: [ { type: "QUICK_REPLY", text } | { type: "URL", text, url, example: [ <url with {{1}} replaced by the example> ] } ] }   (omitted when no buttons; example only when the url ends with {{1}}) ] }
List: GET /{WABA_ID}/message_templates?fields=id,name,language,status,category,components,rejected_reason&limit=100, paging via paging.cursors.after (re-issue the same path with after=<cursor>; never fetch paging.next as a URL). Edit: POST /{TEMPLATE_ID} with { components } (category is not editable). Graph error body: { error: { message, code, error_subcode } }. Rate-limit signals: HTTP 429, or error.code in 4, 17, 32, 613, 80008, 130429.

Plan classification per name|language: absent -> create; present and normalized components equal -> unchanged; present, differs, status APPROVED or PENDING or IN_APPEAL or DISABLED -> drift (APPROVED -> edit only with --allow-edit); present, differs, status REJECTED or PAUSED -> edit.

Output contract (mirrors sync.mjs): one line per template-language "template <name> <language> <create|unchanged|drift|edit|skipped>", then "summary: create=N unchanged=N drift=N edit=N skipped=N"; --status lines "status <name> <language> <STATUS> category=<CATEGORY>" (+ " reason=<rejected_reason>" when REJECTED); --validate prints "valid=<N>"; --sync-chatwoot prints "chatwoot_sync=requested". Exit codes: 0 ok, 1 config/validation error or unresolved drift or --require-approved unmet, 2 API error (incl. rate limit).

Env (never argv): META_SYSTEM_USER_TOKEN, META_WABA_ID (^\d+$, kept as a string), optional META_GRAPH_VERSION (^v\d+\.\d+$, default v25.0); file ~/.config/prestigo/meta-whatsapp.env; parse with parseEnvFile exported by infra/chatwoot/lib/client.mjs. --sync-chatwoot reuses loadChatwootConfig/createChatwootClient from lib/client.mjs and targets the single inbox whose channel_type is Channel::Whatsapp.

Pre-commit facts: SECRET_RE is the single-quoted alternation on the SECRET_RE= line; INFRA_SECRET_KEY_NAMES is derived from every infra/vps/env/*.env.example name containing PASSWORD, SECRET, _KEY or TOKEN and blocks NAME=<value> when the value starts with 4+ characters from [A-Za-z0-9+/_.:=-]. Test fixtures that need an env-file line therefore use values shorter than 4 characters or assemble them at runtime; a Meta-shaped fake token is built at runtime ('EAA' plus a repeated character), never written as a literal.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| owner Mac -> graph.facebook.com | System User token in the Authorization header |
| Graph API responses -> script | untrusted JSON (paging cursors, error text) |
| owner Mac -> Chatwoot API | owner access token for sync_templates |
| git working tree -> repository history | secrets could be committed by mistake |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-78-08 | Information Disclosure | META_SYSTEM_USER_TOKEN in logs, errors, URLs or argv | high | mitigate | env/file loader only (mode 600), Bearer header only, makeGraphRedactor on every error (token, Bearer, access_token, EAA shapes), 300-char cap; tests assert the token never appears |
| T-78-09 | Information Disclosure | token sent to a foreign host via a response-supplied URL (paging.next) or a redirect | high | mitigate | cursor-only paging on the same path, never fetch a URL from a response; redirect 'error' |
| T-78-10 | Tampering / Denial of Service | template deletion blocks the name 30 days; unreviewed edits consume Meta's edit budget | medium | mitigate | DELETE refused in the client; APPROVED drift needs --allow-edit; tests prove no DELETE is ever sent |
| T-78-11 | Information Disclosure | Meta token or WhatsApp secret committed to git | high | mitigate | SECRET_RE EAA shape + whatsapp-meta.env.example names in the KEY=value gate; four probes prove blocking; no-false-positive git grep |
| T-78-12 | Elevation of Privilege | the script becoming a message-sending path (D-12) | medium | mitigate | no /messages path in the script (grep + fake asserts); isolation guard keeps site code away from Meta |
| T-78-SC | Tampering | npm/pip/cargo installs | high | mitigate | Node built-ins only (fetch, AbortSignal, fs); no package installs |
