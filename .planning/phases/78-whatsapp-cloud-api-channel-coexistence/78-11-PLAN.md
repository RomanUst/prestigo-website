| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-78-35 | Elevation of Privilege | over-privileged or wrong-app System User token (e.g. the Marketing app "Prestigo v2") | high | mitigate | dedicated app per D-01; only the new app + WABA assets; only the two WhatsApp permissions; expiration Never recorded for rotation discipline |
| T-78-36 | Information Disclosure | PIN chosen by Chatwoot or leaked through chat/files | high | mitigate | owner registers first at the hidden --register prompt; password manager only; plan 78-12 checks verification_pin_stored=false |

| T-78-38 | Repudiation | display name that does not match the brand leading to rejection or customer confusion | low | mitigate | exact D-05 string; stop-and-ask on DECLINED; customers see the number meanwhile |
| T-78-39 | Tampering | wrong billing currency locked on the WABA | medium | mitigate | one-way decision checkpoint before the card (D-18); --expect-currency EUR check after |
