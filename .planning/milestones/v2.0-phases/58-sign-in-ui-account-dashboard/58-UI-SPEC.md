# Phase 58 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (bespoke dark-theme system in `app/globals.css`) |
| Preset | not applicable |
| Component library | none (Tailwind v4 + custom CSS classes) |
| Icon library | inline SVG only (no external icon library) |
| Font — display | Cormorant Garamond (`var(--font-cormorant)`, `var(--font-display)`) |
| Font — body/UI | Montserrat (`var(--font-montserrat)`, `var(--font-body)`) |

No shadcn. No component library. Every new component MUST use the existing CSS custom classes (`.btn-primary`, `.btn-ghost`, `.btn-secondary`, `.label`, `.display`, `.body-text`, `.wordmark`) and Tailwind v4 utility classes referencing the declared `@theme` color tokens.

---

## Spacing Scale

Standard 8-point scale as already used throughout the codebase:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gap, badge internal padding |
| sm | 8px | Field gap within a form group, dropdown item padding (vertical) |
| md | 16px | Default element spacing, field-to-field margin-bottom |
| lg | 24px | Card internal padding (mobile), section padding |
| xl | 32px | Card internal padding (desktop), form-bottom CTA margin-top |
| 2xl | 48px | Page top padding (`pt-12` / `py-12`) |
| 3xl | 64px | Major page section breaks |

Exceptions:
- Touch targets: minimum `44px` height and `44px` width for all interactive elements (burger menu, dropdown items, form buttons, passenger action buttons) — already enforced in `Nav.tsx` and `globals.css` `.btn-primary`.
- Nav header height: `h-16` (64px) — existing; do not change.
- Dropdown panel: `p-2` (8px) internal, items `px-4 py-3` (16px / 12px) — see Nav Dropdown section.
- Account type toggle buttons: `padding: 10px 20px` to match existing login page pattern.

## Typography

All sizes already established in the codebase; this phase reuses them exactly with no new sizes introduced.

| Role | Family | Size | Weight | Letter-spacing | Line Height | Color var |
|------|--------|------|--------|----------------|-------------|-----------|
| Display heading | Cormorant Garamond | 28px | 400 | 0.12em | 1.1 | `var(--offwhite)` |
| Sub-heading / card title | Cormorant Garamond | 18px | 400 | 0.08em | 1.25 | `var(--offwhite)` |
| Nav link / label / button | Montserrat | 11px | 400 | 0.18–0.35em | 1 | `var(--warmgrey)` → `var(--offwhite)` on hover |
| Body / field value | Montserrat | 14px | 300 | 0.03em | 1.75 | `var(--warmgrey)` |

Additional micro-text (secondary links, "Don't have an account?", error messages):
- 12px / weight 400 / no letter-spacing override / `var(--warmgrey)` (errors: `#e74c3c`)

Nav link size exception: 10px on desktop bar (matches existing `text-[10px]`), 11px on mobile menu (matches existing `text-[11px]`).

## Color

| Role | Hex | Var | Usage |
|------|-----|-----|-------|
| Dominant (60%) | `#28282B` | `var(--anthracite)` | Page background, input background, dropdown backdrop |
| Secondary (30%) | `#36363B` | `var(--anthracite-mid)` | Cards, login card, dropdown panel surface, mobile nav menu |
| Tertiary surface | `#4E4E56` | `var(--anthracite-light)` | Borders: inputs, cards, dropdown, dividers |
| Text primary | `#F5F2EE` | `var(--offwhite)` | Headings, active nav, active tab, selected toggle state |
| Text secondary | `#CFC9C2` | `var(--warmgrey)` | Body text, labels, inactive nav links, placeholder-style copy |
| Accent (10%) | `#D4924A` | `var(--copper-light)` | See reserved list below |
| Accent deep | `#B87333` | `var(--copper)` | Borders on selected state (account-type toggle, mode tab underline), focus ring, scrollbar hover |
| Accent pale | `#E8B87A` | `var(--copper-pale)` | Display italic, shimmer highlight |
| Destructive | `#e74c3c` | (inline, no var) | Inline field error text, delete confirmation prompt text — nowhere else |

**Accent (`var(--copper-light)`) reserved for:**
- "Sign in" button in Nav (guest state) — `.btn-primary` class (border: `var(--copper)`, hover fill: `var(--copper)`)
- Inline text links (e.g., "Create one", "Sign in" switcher on login page) — color: `var(--copper-light)`
- Account dropdown trigger icon/chevron in signed-in state
- Active mode-tab underline border — uses `var(--copper)` (deep, not light)
- Corporate field section label `.copper-line` decoration
- Passenger "Add passenger" CTA — `.btn-secondary` hover border becomes `var(--copper)`
- `:focus-visible` outline across all interactive elements — `var(--copper)` 2px

**Accent is NOT used for:** body text, inactive labels, card surfaces, page backgrounds, plain section headings.

## Surface Specifications

### Nav — Guest State (NAV-01)

Placement: Between the last nav link ("Contact") and the existing "Book now" `.btn-primary`.

Desktop bar:
```
[... nav links ...] [Sign in] [Book now]
```
- "Sign in": `.btn-ghost` class, `style={{ padding: '10px 20px', fontSize: '10px' }}` — matches "Book now" sizing pattern.
- Gap between "Sign in" and "Book now": `gap-3` (12px) — visually tighter than the nav link gap (`gap-8`) to signal CTA grouping.

Mobile menu (inside the slide-down `#mobile-menu` div):
- "Sign in" as a full-width `.btn-ghost` link, `mt-2 mb-1`, rendered immediately above the existing "Book now" `.btn-primary`.
- Min-height: 44px (already enforced by `.btn-ghost`).

### Nav — Signed-In State (NAV-02)

Replace the "Sign in" button with an account trigger. Desktop bar:

```
[... nav links ...] [Account ▾] [Book now]
```

**Account trigger (desktop):**
- `<button>` element, same size slot as "Sign in" was.
- Content: user initial (single uppercase letter) in a 28×28px circle + chevron-down icon (12px).
- Circle: `background: var(--anthracite-mid)`, `border: 1px solid var(--anthracite-light)`, `border-radius: 9999px`, `color: var(--offwhite)`, `font-size: 11px`, `font-family: var(--font-montserrat)`, `letter-spacing: 0.1em`.
- Chevron: inline SVG 12×12px, `color: var(--warmgrey)`, rotates 180° when open (`transition: transform 0.2s ease`).
- Trigger hover: circle border transitions to `var(--copper)`, chevron color to `var(--offwhite)`.
- Min-height: 44px (wrapping `<button>` has `min-h-[44px]`).

**Dropdown panel (desktop):**
- Position: `absolute right-0 top-full mt-2` relative to the trigger.
- Width: `min-w-[160px]`.
- Background: `var(--anthracite-mid)`.
- Border: `1px solid var(--anthracite-light)`.
- Border-radius: `4px`.
- Box-shadow: `0 8px 24px rgba(0,0,0,0.4)`.
- Padding: `p-2` (8px) wrapper.
- Open/close: CSS `opacity` + `pointer-events` transition, 150ms ease-out.
- Close on: outside click, Escape key, navigation.
- `aria-expanded` on trigger, `role="menu"` on panel.

**Dropdown items:**
- Three items: "My trips" → `/account/trips`, "Profile" → `/account/profile`, "Sign out" (form action).
- Layout: `<Link>` / `<button>` full-width, `px-4 py-3` (16px / 12px), `min-h-[44px]`.
- Font: Montserrat, 11px, weight 400, `letter-spacing: 0.18em`, `text-transform: uppercase`, color `var(--warmgrey)`.
- Hover: background `rgba(255,255,255,0.04)`, color `var(--offwhite)`, transition 150ms.
- Divider before "Sign out": `1px solid var(--anthracite-light)`, `mx-2 my-1`.
- "Sign out" item color at rest: `var(--warmgrey)` — NOT red; destructive colour only at confirmation step elsewhere.
- `role="menuitem"` on each item.

**Mobile signed-in state (inside `#mobile-menu`):**
- Replace the "Sign in" `.btn-ghost` with flat inline links in the same list position.
- Three items as plain `<Link>` / `<button>` rows, same 44px min-height, `text-[11px] tracking-[0.2em] uppercase text-warmgrey hover:text-offwhite`.
- "Sign out" as the last item in the list, styled identically to other mobile nav links (NOT red, no border, consistent with luxury restraint).
- "Book now" `.btn-primary` remains the last element.

#### Section 1 — Contact Details

Section label (`.label`): "Contact Details"

**Fields and order:**
1. Full name — editable text input.
2. Email — read-only display (not an editable `<input>`).
3. Phone — editable text input.
4. Account type — toggle (Personal / Corporate).

**Shared input style** (mirror `app/login/page.tsx` `inputStyle`):
```
width: 100%, padding: 12px 14px,
backgroundColor: var(--anthracite),
border: 1px solid var(--anthracite-light),
borderRadius: 4px,
color: var(--offwhite),
fontSize: 14px (enforced by globals.css),
fontFamily: var(--font-montserrat),
```
Focus state: `border-color: var(--copper)`, `outline: none` (`:focus-visible` from globals handles outer ring if needed).

**Field label style** (mirror `labelStyle` from login page):
```
display: block,
fontSize: 11px,
color: var(--warmgrey),
letterSpacing: 0.18em,
textTransform: uppercase,
marginBottom: 8px,
```

**Field wrapper:** `marginBottom: 16px`.

**Email field (read-only):**
- Rendered as `<p>` styled like the input (same padding/border/background) with `color: var(--warmgrey)` instead of offwhite (visually de-emphasised).
- Below the email "p": a sub-caption `fontSize: 12px, color: var(--warmgrey), marginTop: 4px` — Copy: "Email cannot be changed here."

**Phone field:**
- `type="tel"`, `autoComplete="tel"`.

**Account type toggle:**
- Identical to the pattern in `app/login/page.tsx` — two side-by-side buttons, `flex gap-2`.
- Each button: `flex: 1`, `padding: 10px 20px`, `border: 1px solid`, `borderRadius: 4px`, `background: transparent`, `fontSize: 11px`, `letterSpacing: 0.18em`, `textTransform: uppercase`, `fontFamily: var(--font-montserrat)`, `minHeight: 44px`, `transition: border-color 0.15s ease, color 0.15s ease`.
- Active state: `borderColor: var(--copper)`, `color: var(--offwhite)`.
- Inactive state: `borderColor: var(--anthracite-light)`, `color: var(--warmgrey)`.
- Labels: "Personal" and "Corporate".

**Corporate fields (conditional block):**
- Shown only when `account_type === 'corporate'`.
- Entrance animation: `animate-step-enter` (already defined in globals.css — `stepFadeUp 0.3s cubic-bezier(0.22, 1, 0.36, 1) forwards`).
- Sub-label separating corporate block: `.label` class, copy "Company Details", `marginTop: 8px marginBottom: 16px`.
- Fields in order:
  1. Company name — `type="text"`, `autoComplete="organization"`.
  2. IČO — `type="text"`, `inputMode="numeric"`, label copy: "IČO (Company ID)".
  3. DIČ / VAT — `type="text"`, label copy: "DIČ / VAT ID".
- Same input style and field wrapper as contact fields.
- All three corporate fields are optional (no `required` attribute) — placeholder text style: `color: var(--anthracite-light)`.

**Save button:**
- `.btn-primary` class, `width: 100%`, `marginTop: 32px`.
- Label: "Save changes"
- Pending state: `opacity: 0.7`, `cursor: wait`, `pointerEvents: none`, label changes to "Saving…"
- Success state: inline confirmation below the button — `fontSize: 12px, color: var(--copper-light), letterSpacing: 0.08em, marginTop: 8px`. Copy: "Changes saved."
- Error state: same position as success, `color: #e74c3c`. Copy: "Something went wrong. Please try again."

## Interaction Contracts

### Nav Dropdown

| Trigger | Behaviour |
|---------|-----------|
| Click account trigger | Toggle panel open/closed |
| Escape key (panel open) | Close panel, return focus to trigger |
| Click outside panel | Close panel |
| Navigate to any item | Close panel, navigate |
| Scroll | Panel stays open (no scroll-close) |
| Pre-hydration | Guest state shown (Sign in button); no flash of signed-in state → acceptable per D-09 |

### Profile Form

| Trigger | Behaviour |
|---------|-----------|
| Switch to Corporate | Corporate fields animate in (`animate-step-enter`) |
| Switch to Personal | Corporate fields animate out (opacity 0 → remove from DOM after 150ms) |
| Submit with network error | Error text below button; form stays populated (no reset) |
| Submit success | Success text below button; disappears after 3s |

### Passenger Editor

| Trigger | Behaviour |
|---------|-----------|
| Click "Add passenger" | Editor slides in below list (`animate-step-enter`) |
| Click "Edit [name]" | Row expands inline with editor pre-populated |
| Click "Cancel" | Editor collapses, no save |
| Click "Delete [name]" | Confirmation bar opens below that row |
| Click "Cancel" in confirmation | Confirmation bar closes |
| Click "Delete" in confirmation | Server action fires; pending: button opacity 0.7; success: row removed |

## Accessibility Anchors

- All interactive elements: `:focus-visible` outline `2px solid var(--copper)`, `outline-offset: 4px` (from globals.css).
- All buttons/links: `min-height: 44px` touch target.
- Nav dropdown: `aria-expanded` on trigger, `role="menu"`, `role="menuitem"` on items.
- Error messages: `role="alert"` (matches existing login page pattern).
- Passenger edit/delete icon buttons: explicit `aria-label` with passenger name.
- Corporate fields: rendered conditionally in DOM (not hidden with CSS) to prevent screen readers from reading hidden fields.
- `prefers-reduced-motion`: all `animate-step-enter` and transition durations collapse to `0.01ms` (from globals.css rule).
