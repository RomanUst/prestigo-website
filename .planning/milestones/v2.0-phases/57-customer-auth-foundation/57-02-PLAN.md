<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /login server actions | Untrusted form input (email, password, account_type, return-to) crosses to server |
| browser → /auth/callback | OAuth code / email token_hash + attacker-controllable return-to param |
| customer session ↔ admin session | Same auth.users store; privilege decided by app_metadata.is_admin |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-57-05 | Tampering | open redirect via return-to on /login + /auth/callback | mitigate | safeReturnTo() relative-path-only (`/` prefix, reject `//` and absolute); covered by auth-callback open-redirect test |
| T-57-06 | Elevation of Privilege | non-admin customer reaching /admin | mitigate | middleware D-11 branch redirects non-admin off /admin to /; getAdminUser unchanged |
| T-57-07 | Spoofing | session forgery via getSession() | mitigate | All gating uses getUser() (JWT-validated); getSession never used |
| T-57-08 | Denial of Service | brute force / magic-link bombing on /login | mitigate | checkRateLimit('/login', ip) 5/min (fail-open for UX) |
| T-57-09 | Tampering | OAuth state/PKCE forgery | mitigate | Supabase @supabase/ssr PKCE handles state automatically; not disabled |
| T-57-10 | Information Disclosure | email enumeration via password reset | mitigate | sendPasswordReset always returns { success: true } |
| T-57-11 | Tampering | CSRF on sign-in/sign-out server actions | accept | Next.js server-action IDs + SameSite=Lax cookies provide CSRF defense for non-/api actions; no /api mutation path added (A7) |
| T-57-12 | Denial of Service | CSP blocks OAuth redirect | mitigate | connect-src + form-action allow accounts.google.com / appleid.apple.com |
</threat_model>
