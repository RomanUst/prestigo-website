- Header comment: run order (82-14/82-15): owner marks desk numbers shared -> identity pass -> report reviewed -> crm_sync_start set -> enqueue 'bf'; re-runs use 'bf2', 'bf3'...; QStash budget about 4 messages per booking (RESEARCH A10).
