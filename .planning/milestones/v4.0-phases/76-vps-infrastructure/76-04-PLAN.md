## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet -> Caddy :80/:443 | public HTTPS entry to both apps (must stay public per D-17) |
| Caddy -> app containers (edge network) | internal plaintext hop on the host |
| app containers -> Resend | system mail relay |
| Docker Hub -> host | third-party images executed on the host |
