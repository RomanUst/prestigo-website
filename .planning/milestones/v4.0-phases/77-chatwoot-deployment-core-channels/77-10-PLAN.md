<objective>
The visitor-facing chat entry point (INBOX-02/03/04; D-01..D-09, D-16): a brand launcher on every public page that loads nothing third-party until "Chat on site" is clicked, then opens the Chatwoot widget in the page's language, identified for signed-in customers and carrying visit context for the operator and Phase 85 analytics.

Consent record (Claude's discretion, D-02): the click is the consent; each conversation stores chat_consent='click-to-open' and chat_opened_at as custom attributes — an audit trail inside Chatwoot with no new site storage. Documented on the privacy page by plan 77-05.
First-touch UTM (D-06): the landing URL is captured in memory when the launcher first mounts (no cookie, no storage, no network) and used at click time.
Verification split: the full site path is proven by an end-to-end test through the real identity route handler with a fake Chatwoot SDK; the real widget is exercised on production in plan 77-12 (the Website inbox only accepts rideprestigo.com).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| visitor click -> third-party widget | the consent boundary (D-02) |
| browser URL/referrer/store -> Chatwoot attributes | client-controlled data sent to the operator tool |
| identity route response -> script injection | the loader injects a script from a server-supplied URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-77-24 | Information Disclosure | third-party load before consent | high | mitigate | loader only reachable through the click handler's dynamic import; tests assert no script/fetch on mount; probe consent mode on 7 locales locally and on production (77-12) |
| T-77-25 | Tampering | visit-context injection (oversized/control characters) | low | mitigate | buildVisitContext strips control chars, trims, caps at 200 chars (tested) |
| T-77-26 | Information Disclosure | PII in URL query strings forwarded to Chatwoot | medium | mitigate | page_url/landing_url/referrer keep only origin, path and utm_* (tested) |
| T-77-27 | Spoofing | script injected from an unexpected origin | low | mitigate | isSafeWidgetBaseUrl (https origin only) checked before injection; base URL comes only from the server route |
| T-77-SC | Tampering | npm/pip/cargo installs | high | mitigate | no package installs (lucide-react already a dependency); package-legitimacy gate not triggered |
</threat_model>
