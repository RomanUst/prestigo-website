Commits use the `security:` prefix (CSP + guard + session hygiene).

middleware.ts facts (plan time): buildCsp(nonce) is used only when the RAW pathname starts with /admin or /driver; every other response (all public pages including /book, /login, /account, and /api/*) gets buildCspStatic(). buildCspStatic's script-src is a ternary of two string literals (development adds 'unsafe-eval' 'self'); each directive is one double-quoted string literal on its own line inside an array joined with '; '.

Guard exemption spec (tests/infra-vps-isolation-guard.test.ts):
- CSP_EXEMPT_FILE = 'middleware.ts'
- CSP_DIRECTIVE_LINE_RE: optional leading whitespace, optional "? " or ": " (ternary branch), then a quote character (double, single or backtick) captured as group 1, then one directive name from default-src, script-src, style-src, img-src, font-src, connect-src, frame-src, media-src, worker-src, form-action, then whitespace, then any characters that are not the group-1 quote, then the same quote, optional comma, optional trailing whitespace, end of line (backreference to group 1 so directive strings containing the other quote type still match)
- In findVpsViolations step 1, a host-literal line hit is skipped only when filePath === CSP_EXEMPT_FILE and the line matches CSP_DIRECTIVE_LINE_RE. The env-var check and the package-import check are NOT exempted.
Chatwoot widget cookies (set by the SDK on the site origin after the click): cw_conversation and cw_user_<websiteToken>.
