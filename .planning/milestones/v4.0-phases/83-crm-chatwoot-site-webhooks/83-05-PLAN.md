webhook.mjs contract (`infra/espocrm/webhook.mjs`, ESM, CLI + exported functions for tests):
- `WEBHOOK_EVENT = 'Contact.update'`, `DEFAULT_WEBHOOK_URL = 'https://rideprestigo.com/api/webhooks/espocrm'`, `WEBHOOK_ENV_FILE = <CONFIG_DIR>/espocrm-webhook.env`.
- `parseWebhookArgs(argv)` -> `{ command: 'create' | 'list' | 'delete' | 'print' | 'probe', id?, printKind?: 'secret' | 'id', url, allowHost: boolean }`; refuses a non-https url or a host other than rideprestigo.com unless `--allow-host`; refuses a delete id that is not 17 lowercase hex.
- `espoSignature(webhookId: string, secret: string, body: string): string` (exported so plan 83-11 can cross-check it against the site verifier).
- `runWebhook({ argv, client, fetchImpl, configDir, isTTY, out, err })` -> exit code; output is fixed `key=value` lines; never the secret; list lines `id=<id> event=<event> active=<bool> skipOwn=<bool> owner=<set|none>`.
- create: GET existing webhooks for WEBHOOK_EVENT + url -> found: print `webhook=exists id=<id> skipOwn=<bool>` (exit 1 when skipOwn is false); else POST, then GET /Webhook/<id> and require skipOwn true and a non-empty userId (else exit 1, `error=skipown_not_effective`), then write the env file with mode 0o600 (directory 0o700) and print `webhook=created id=<id> skipOwn=true`.
- print: refuses when isTTY (exit 1, message on err); otherwise writes the stored value without a trailing newline.
- probe: body = JSON.stringify([{ id: <random 17-hex>, firstName: 'Probe' }]); POST url with `Content-Type: application/json` and `Signature`; then the same signature with a changed body; verdict=ok when the statuses are exactly 200 then 401, else verdict=fail and exit 1; prints `probe_status=<a>,<b>`.
