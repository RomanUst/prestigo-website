<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Chatwoot SPA (parent window) -> iframe | postMessage carries the conversation context |
| any other window -> iframe | forged postMessage attempts |
| iframe -> panel API | token header + conversation id |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-84-29 | Spoofing | forged postMessage supplying a conversation id | high | mitigate | exact origin + source === window.parent; server re-verifies the id with the operator's token (a forged id still needs Chatwoot access) |
| T-84-30 | Information Disclosure | context posted to an unintended window | medium | mitigate | fetch-info posted with the exact Chatwoot origin as targetOrigin; inert when not framed |
| T-84-31 | Information Disclosure | operator token readable by marketing-page scripts | high | mitigate | sessionStorage only (D-02), tests spy that the persistent storage is never written; 401 clears it; Forget token in 84-08 |
| T-84-32 | Tampering | stored XSS via booking text | medium | mitigate | React text rendering only, no raw HTML (grep gate), nonce CSP default-src 'none' |
| T-84-33 | Elevation of Privilege | admin cookie sent with the panel fetch | medium | mitigate | credentials 'omit' on the fetch, plus the middleware strip (84-05) and the route guard (84-04) |
| T-84-SC | Tampering | npm/pip/cargo installs | high | mitigate | no package installs in this plan |
</threat_model>
