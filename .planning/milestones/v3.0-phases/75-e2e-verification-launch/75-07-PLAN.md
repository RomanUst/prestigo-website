## Translation rules (D-08) — apply to every in-session translation in this plan

1. You are the translator (Anthropic credit is empty; the i18n Translate workflow is disabled). Never run `node scripts/i18n-translate.mjs` in any mode other than `--check`.
2. Keep verbatim (i18n/glossary.json doNotTranslate): Prestigo, PRESTIGO, chelautotrans s.r.o., Mercedes-Benz, E-Class, S-Class, V-Class, rideprestigo.com, phone numbers, € / Kč amounts, times, flight numbers, and every `{placeholder}`.
3. Place names: use the exonym the locale already uses in `content/routes/<locale>/*.json` (read `hero.label` of the matching route file); route strings like "Prague · Brno · Warsaw" use those exonyms.
4. Register: premium, plain, short sentences; zh = Simplified Chinese; ar = Modern Standard Arabic; hi = Devanagari Hindi with brand tokens kept in Latin inside the sentence.
5. Structure: identical key set, value types, array lengths and order to the EN file; nothing left in English except DNT-only values.
6. EN strings are moved verbatim; EN rendered output must stay byte-identical.
7. Freeze file format: one pattern per line (`<sourceKey>` or `<sourceKey>::<dotPathPrefix>`), `#` comments; applied by plan 75-18.
