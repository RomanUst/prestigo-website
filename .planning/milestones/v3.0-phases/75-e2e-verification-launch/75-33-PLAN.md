- node_modules/next/dist/lib/metadata/resolve-metadata.js collectMetadata(): when rendering an error convention (not-found), Next collects the LAYOUT metadata of each segment plus the not-found module's metadata via getDefinedMetadata(errorMod, props) — which calls `generateMetadata(props, parent)` when the module exports it. props at the app/[locale] level = { params } including `locale`.
