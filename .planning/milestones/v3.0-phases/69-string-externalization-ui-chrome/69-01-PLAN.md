Wire the complete next-intl message pipeline end-to-end and prove it on ONE component (Nav) — the tracer that de-risks the whole phase before any other component is touched.

Output: messages/en.json (Nav namespace) + 6 stubs, the request/routing/provider wiring, the vitest harness, and Nav rendering through useTranslations with locale-aware links, all green.
